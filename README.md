Helena é um projeto acadêmico com o intuito de ser um estudo e um caso de pesquisa 
de como a interface do usuário, por meio de pesquisas de UX e UI Design, pode interferir 
na forma como interagimos com o conteúdo presente dentro do nosso app, e como 
podemos ter uma maior adesão ou não aos sistemas presentes dentro do nosso app.
Com isso, temos que para facilidade do desenvolvimento, a stack escolhido foi 
a mesma, por apresentar grande velocidade no desenvolvimento das features, assim como
apresentar grande qualidade dentro da produção de novas interfaces visuais e na 
forma como as novas features podem ser evoluidas tanto em ambientes android
como em ambientes iOS.
